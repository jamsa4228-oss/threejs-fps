DUSTLINE — a round-based tactical FPS in three.js. You are the attacker: plant the spike at Site A or Site B, or eliminate the four defenders, before the round timer runs out. Win rounds to earn money, spend it in the buy menu on rifles, SMGs, grenades and armor, and take the match first to 5 round wins. Single-player against bots, fully offline — three.js 0.187.0 is vendored, all sounds are synthesized with WebAudio, no network request is made at runtime.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — click to play, WASD to move, mouse to aim, click to fire, R to reload, B for the buy menu, E to plant/defuse the spike, G to throw a grenade, Ctrl to crouch, Space to jump.
